# Локальные эмбеддинги и анализ позиций через DeepSeek

Статус: принято.

## Контекст

Эмбеддинги нужны для поиска близких формулировок. Определение политического вопроса, собственной позиции автора и совпадения позиций требует отдельного анализа. В проекте уже используется DeepSeek для анализа политических высказываний.

## Решение

Считать эмбеддинги локально. Использовать DeepSeek для выделения политических вопросов и позиций, а также проверки совпадения вопросов и позиций. Тексты анализируемых комментариев отправляются во внешний API OpenRouter, где используется модель DeepSeek.

Для первой версии использовать `intfloat/multilingual-e5-base` с зафиксированной ревизией модели. Привязывать сохранённые эмбеддинги к этой ревизии. Модель используется для поиска близких формулировок, а не как самостоятельное подтверждение согласия авторов.

Выбрана ревизия `d128750597153bb5987e10b1c3493a34e5a4502a`. Для DeepSeek используется OpenRouter: ключ `OPENROUTER_API_KEY`, имя модели `OPENROUTER_MODEL` (по умолчанию `deepseek/deepseek-v4-flash-0731`), маршрут `OPENROUTER_PROVIDER` (по умолчанию `deepinfra/fp8`), версии правил и явное поколение `POSITION_ANALYSIS_GENERATION`. Адрес API, модель, маршрут и параметры запроса входят в версию кеша. Возвращаемые модель, провайдер и fingerprint проверяются между запросами; обнаруженное изменение останавливает обработку до перехода на новое поколение анализа.

Сохранять результаты анализа и обрабатывать новые комментарии без повторного анализа уже обработанных при неизменных настройках. Привязывать результаты к версиям модели и правил анализа.

При изменении версии сохранять предыдущий результат с пометкой «Требуется обновление». Пересчёт выполняется по кнопке; результаты разных версий не смешиваются в одной оценке.

## Последствия

Используется существующий внешний сервис для понимания текста; локальные эмбеддинги обеспечивают поиск кандидатов. Анализ зависит от доступности и стоимости DeepSeek, а сохранённые результаты — от используемых настроек и правил анализа.

Полностью локальный анализ не выбран. Использование внешнего API для вычисления эмбеддингов также не выбрано.

## Источник

[Карточка multilingual-e5-base](https://huggingface.co/intfloat/multilingual-e5-base): поддержка русского языка, размерность эмбеддингов 768 и требования к префиксам входного текста.

## Маршрут OpenRouter

Все клиенты DeepSeek используют `https://openrouter.ai/api/v1/chat/completions`. Для модели отключается reasoning (`reasoning.enabled=false`); `provider.require_parameters=true` не разрешает игнорировать обязательные параметры. `provider.only` закрепляет выбранный маршрут, `allow_fallbacks=false` исключает незаметную замену сервера. При изменении настроек прежний завершённый результат сохраняется, пересчёт запускается явно.

[Модель и маршруты](https://openrouter.ai/api/v1/models/deepseek/deepseek-v4-flash-0731/endpoints), [настройки провайдера](https://openrouter.ai/docs/guides/routing/provider-selection).
