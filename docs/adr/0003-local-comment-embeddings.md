# Локальные эмбеддинги самих комментариев

Статус: принято для текущего веб-анализатора; заменяет выполнение через DeepSeek
из ADR 0002 в разделе сравнения авторов.

## Причина

Пользователь просит создавать эмбеддинги локальной моделью без DeepSeek. Предыдущий
пайплайн сначала отправлял всю историю во внешний API и кодировал только выделенные
вопросы, что делало первый запуск медленным и платным.

## Решение

Кнопка сравнения запускает `LocalTextAnalysis`. Локальная E5 кодирует каждый уникальный
непустой комментарий, в том числе ранее не обработанный DeepSeek. Ключ OpenRouter не
нужен. Веса скачиваются при первом использовании; исходные тексты не отправляются
для inference во внешний API. Вычисление идёт пакетами на CPU или CUDA, в отдельном
потоке. Длинные тексты делятся по токенам без обрезания конца; нормализованные векторы
частей усредняются с весом по количеству токенов и повторно нормализуются.

Векторы сохраняются в SQLite как JSON-массивы, namespace
`comment-embeddings:<версия E5 и алгоритма>`. Кеш читается страницами по 256 записей,
матрица хранится в памяти как float32. При возобновлении вычисляются только отсутствующие
векторы. Метаданные метода отличают эти результаты от прежней оценки согласия.

Для быстрого сравнения всех авторов усредняются векторы уникальных комментариев каждого
автора; средний вектор нормализуется. Рейтинг использует косинусное сходство и содержит
до десяти авторов. Примеры выбираются из 32 текстов, ближайших к среднему вектору
каждого автора; показываются до пяти наиболее похожих пар без повторения примера.

## Ограничения

Этот режим показывает сходство текстов. Он не выделяет только политические комментарии,
не определяет согласие или расхождение мнений и не выбирает последнюю ясно выраженную
политическую позицию. Прежние названия и оценки согласия не используются для нового
рейтинга. Отдельный анализ политических координат не изменён.

Первый запуск требует скачивания весов; затем кодирование не требует внешнего API.
Время первого прохода зависит от CPU/GPU и длины комментариев. Реальная модель не
скачивалась при проверке изменения; вычислительная логика проверяется на PyTorch
с подставными токенизатором и моделью, а пайплайн — с локальным FakeEmbedder.
